# Arena das Cartas — Pacote 1 (protótipo)

Este pacote é um **protótipo navegável**, não uma plataforma de apostas nem um jogo multiplayer concluído.

## Instalação
Envie todos os arquivos à raiz de um repositório GitHub e publique usando GitHub Pages (Settings > Pages > Deploy from branch > main / root). Abra o endereço HTTPS, instale como aplicativo e acesse novamente após o primeiro carregamento para testar o cache offline.

## Funciona agora
- Catálogo visual das 7 modalidades
- Baralho de 52 cartas embaralhado e compra interativa local
- Preferências de áudio salvas no dispositivo
- PWA com cache offline básico

## Próximas implementações
- Motores completos e validados das regras de cada jogo
- Robôs offline e multiplayer em tempo real
- Cadastro, login, banco Supabase, painel Master e ranking
- Onze arquivos sonoros reais licenciados, com pré-carregamento offline
- Economia virtual de testes, sem depósitos ou saques reais

**Importante:** Não existe Pix, apostas, premiações ou carteira real neste pacote. Não há integração Supabase ainda. Não inclua chaves secretas do Supabase no código público.
